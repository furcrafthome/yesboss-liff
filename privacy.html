นโยบายความเป็นส่วนตัว (Privacy Policy)

1. นโยบายนี้คืออะไร ใช้กับอะไรบ้าง

นโยบายฉบับนี้อธิบายว่า YES BOSS เก็บรวบรวม ใช้ และดูแลข้อมูลส่วนบุคคลของคุณอย่างไร ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) โดยครอบคลุมบริการทั้งหมดของ YES BOSS ได้แก่ บัญชีทางการ LINE, เว็บแอป "My YES BOSS" และหน้าลงทะเบียนนี้

2. ใครเป็นผู้ควบคุมข้อมูล

ทีมผู้พัฒนา YES BOSS เป็นผู้ควบคุมข้อมูลส่วนบุคคลของคุณ มีหน้าที่ดูแลข้อมูลให้ปลอดภัยตามกฎหมาย

ติดต่อเรา: ทักหาเลขา YES BOSS ในแชต LINE @yes_boss ได้ตลอด — เป็นช่องทางหลักของเรา ทุกเรื่องข้อมูลส่วนบุคคลส่งถึงทีมงานโดยตรง

3. เราเก็บข้อมูลอะไรบ้าง

หมวดตัวอย่าง
ข้อมูลลงทะเบียนชื่อที่ให้เลขาเรียก, เบอร์โทร (ถ้าให้), ช่วงอายุ, ฟีเจอร์ที่สนใจ, ช่องทางที่รู้จักเรา
ข้อมูลบัญชี LINEรหัสผู้ใช้ (userId) จาก LINE — เราไม่เห็นรหัสผ่านหรือแชตอื่นของคุณ
เนื้อหาที่สั่งงานข้อความและเสียงที่ส่งหาเลขา เพื่อให้เลขาทำงานตามสั่ง
สิ่งที่ให้เลขาจดงาน นัดหมาย รายการรายรับรายจ่าย รูปสลิป/ใบเสร็จ ไฟล์เอกสารที่ฝากเก็บ
ความรู้สึกโดยรวมเมื่อใช้โหมดฮีลใจ ระบบจดบันทึกเพียง "อารมณ์โดยรวม" ไว้เพื่อดูแลคุณ — ข้อความที่ระบายไม่ถูกเก็บบันทึก
ข้อมูลการใช้งานเวลาที่ใช้ ฟีเจอร์ที่ใช้ เพื่อความปลอดภัยและปรับปรุงบริการ
💡 เราเก็บเท่าที่จำเป็นต่อการเป็นเลขาให้คุณเท่านั้น ไม่มีการแอบเก็บรายชื่อผู้ติดต่อ ตำแหน่งที่ตั้ง หรือแชตอื่นใน LINE ของคุณ

4. เอาข้อมูลไปใช้ทำอะไร (และใช้ฐานกฎหมายใด)

  • ให้บริการเลขา — จดงาน เตือนนัด สรุปรายวัน บันทึกเงิน ค้นคืนไฟล์ (ฐานการปฏิบัติตามสัญญา)
  • ประมวลผลคำสั่งด้วยระบบอัตโนมัติ (AI) — เพื่อเข้าใจสิ่งที่คุณพิมพ์/พูด แล้วทำงานให้ถูกต้อง (ฐานการปฏิบัติตามสัญญา)
  • ความปลอดภัยของระบบ — ป้องกันการใช้งานผิดปกติ สแปม หรือการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต (ฐานประโยชน์โดยชอบด้วยกฎหมาย)
  • ปรับปรุงบริการ — วิเคราะห์ภาพรวมการใช้งาน (ไม่เจาะรายบุคคล) เพื่อพัฒนาฟีเจอร์ (ฐานประโยชน์โดยชอบด้วยกฎหมาย)
  • ข่าวสารและสิทธิพิเศษ — ส่งเฉพาะเมื่อคุณติ๊กยินยอมแยกไว้เท่านั้น และยกเลิกได้ทุกเมื่อ (ฐานความยินยอม)

5. เปิดเผยข้อมูลให้ใครบ้าง

เราไม่ขายข้อมูลของคุณให้ใครเด็ดขาด ข้อมูลจะถูกส่งต่อเฉพาะผู้ให้บริการระบบที่จำเป็นต่อการทำงาน ภายใต้ข้อตกลงคุ้มครองข้อมูล ได้แก่

  • LINE — แพลตฟอร์มรับส่งข้อความ
  • ผู้ให้บริการคลาวด์และฐานข้อมูล — จัดเก็บข้อมูลอย่างปลอดภัย (เซิร์ฟเวอร์ภูมิภาคเอเชียตะวันออกเฉียงใต้ ประเทศสิงคโปร์)
  • ผู้ให้บริการประมวลผลภาษา (AI) — ประมวลผลคำสั่งของคุณ ซึ่งเซิร์ฟเวอร์อาจอยู่ต่างประเทศ โดยเราเลือกผู้ให้บริการที่มีมาตรฐานคุ้มครองข้อมูลระดับสากล

กรณีที่กฎหมายกำหนด เช่น คำสั่งศาลหรือหน่วยงานรัฐที่มีอำนาจ เราอาจจำเป็นต้องเปิดเผยข้อมูลตามขอบเขตที่กฎหมายบังคับเท่านั้น

🤖 ข้อมูลของคุณไม่ถูกนำไปฝึกโมเดล AI: ข้อความและรูปที่คุณส่งเข้ามาถูกส่งไปประมวลผลผ่าน API ของผู้ให้บริการ AI ภายใต้เงื่อนไขที่กำหนดว่าไม่นำข้อมูลที่ส่งผ่าน API ไปฝึกหรือปรับปรุงโมเดล — ไม่มีข้อมูลของคุณกลายเป็นส่วนหนึ่งของโมเดลที่คนอื่นใช้

💳 เราไม่เก็บข้อมูลบัตรของคุณ: การชำระเงินเป็นการโอนผ่านพร้อมเพย์แล้วส่งสลิปในแชต — ระบบเราไม่เคยรับและไม่เคยเก็บเลขบัตรเครดิต/เดบิตหรือรหัสธนาคารของคุณเลย

6. การเชื่อมต่อ Google Calendar (ข้อมูลจาก Google)

YES BOSS มีฟีเจอร์เสริม "ผูกปฏิทิน Google" ที่ทำงานเฉพาะเมื่อคุณกดยินยอมเชื่อมต่อบัญชี Google ด้วยตัวเองเท่านั้น หากคุณไม่ผูก ฟีเจอร์นี้จะไม่เข้าถึงข้อมูล Google ใดๆ ของคุณเลย เมื่อคุณเลือกผูก เราจะขอสิทธิ์ผ่านระบบ OAuth ที่ปลอดภัยของ Google ตามรายละเอียดนี้

หัวข้อรายละเอียด
สิทธิ์ที่ขอ① เข้าถึงและจัดการเหตุการณ์ในปฏิทิน (ขอบเขต calendar.events) เพื่อสร้าง แก้ไข และลบเฉพาะรายการนัดหมายที่คุณสั่งผ่าน YES BOSS เท่านั้น
② จัดการรายการงานของคุณ (ขอบเขต tasks) — ใช้เมื่อคุณเปิดฟีเจอร์ "ดึงนัดจากปฏิทิน" เอง เพื่ออ่านงานที่คุณตั้งวันครบกำหนดไว้ มาเตือนให้ และติ๊กว่าเสร็จกลับไปให้เมื่อคุณกดเสร็จในแชต (Google แสดงงานรวมอยู่ในแอปปฏิทิน แต่เป็นคนละระบบกัน จึงต้องขอสิทธิ์แยก)
นำไปใช้ทำอะไรเมื่อคุณตั้ง แก้ หรือลบนัดหมายกับเลขา ระบบจะซิงก์รายการนั้นเข้า Google Calendar ของคุณอัตโนมัติ เพื่อให้นัดของคุณอยู่ครบในที่เดียว
เก็บข้อมูลอะไรเก็บเพียงโทเคนการเข้าถึง (refresh token) เพื่อซิงก์ต่อเนื่องโดยไม่ต้องขอสิทธิ์ใหม่ทุกครั้ง และรหัสอ้างอิงของเหตุการณ์ที่เราสร้างขึ้น — โดยปกติเราไม่อ่านปฏิทินของคุณเลย (เขียนอย่างเดียว) เว้นแต่คุณเปิดฟีเจอร์ "ดึงนัดจากปฏิทิน" ด้วยตัวเอง ตามรายละเอียดในแถวถัดไป
📥 ดึงนัดจากปฏิทิน
(ต้องเปิดเอง)		ปิดไว้เป็นค่าเริ่มต้น — เราจะไม่อ่านนัดในปฏิทินของคุณจนกว่าคุณจะพิมพ์ว่า "ดึงนัดจากปฏิทิน" ในแชตด้วยตัวเอง
เมื่อเปิดแล้ว: เราอ่านเฉพาะนัดและงานที่ตั้งวันครบกำหนดไว้ ในช่วง 90 วันข้างหน้า จากปฏิทินในบัญชี Google ที่คุณผูกไว้ (เฉพาะปฏิทินที่คุณเป็นเจ้าของ — ไม่รวมปฏิทินวันหยุดหรือวันเกิดที่คุณกดติดตามไว้) เพื่อสร้างเป็นรายการนัดใน YES BOSS ให้คุณ (เตือนได้ กดเสร็จได้ เห็นในสรุปเช้า) · เก็บเฉพาะชื่อนัดและเวลา ไม่เก็บผู้เข้าร่วม ไม่เก็บรายละเอียดอื่น · ไม่ส่งเนื้อหานัดไปให้ระบบ AI (ขั้นตอนนี้ไม่ผ่าน AI เลย) · แก้ชื่อหรือเวลาของนัดเหล่านี้ใน YES BOSS จะอัปเดตกลับไปที่ปฏิทิน/งานของคุณให้ตรงกัน · กด "เสร็จแล้ว" กับงาน = ติ๊กว่าเสร็จใน Google ให้ด้วย แต่นัดในปฏิทินจะไม่ถูกลบ (เก็บไว้เป็นประวัติ)
ปิดเมื่อไหร่ก็ได้: พิมพ์ "ปิดการดึงนัดจากปฏิทิน"
ยกเลิกได้ทุกเมื่อพิมพ์ "ยกเลิกผูกปฏิทิน" ในแชต หรือถอนสิทธิ์ที่ myaccount.google.com/permissions — เมื่อถอนแล้วเราลบโทเคนทิ้งทันที
🔒 การใช้งานแบบจำกัด (Limited Use): การที่ YES BOSS ใช้และถ่ายโอนข้อมูลที่ได้รับจาก Google API เป็นไปตามนโยบายข้อมูลผู้ใช้ของบริการ Google API (Google API Services User Data Policy) รวมถึงข้อกำหนดการใช้งานแบบจำกัด (Limited Use) เราใช้ข้อมูล Google Calendar ของคุณเพียงเพื่อให้บริการซิงก์นัดหมายตามที่คุณสั่งเท่านั้น ไม่นำไปใช้เพื่อโฆษณา ไม่ขายต่อ และไม่ให้บุคคลอ่าน เว้นแต่คุณอนุญาต เพื่อความปลอดภัยของระบบ หรือเมื่อกฎหมายกำหนด

🤖 ไม่นำข้อมูล Google ไปฝึก AI: เราไม่นำข้อมูลผู้ใช้จาก Google (รวมถึงข้อมูลปฏิทิน) ไปใช้ ส่งต่อ หรือฝึกฝน/พัฒนาโมเดลปัญญาประดิษฐ์ (AI/ML) ใดๆ และไม่ส่งข้อมูลจาก Google ไปยังผู้ให้บริการ AI ภายนอก ระบบ AI ที่ YES BOSS ใช้มีไว้เพื่อเข้าใจข้อความที่คุณพิมพ์เองเท่านั้น ประมวลผลผ่าน API ที่ผู้ให้บริการไม่นำข้อมูลไปฝึกโมเดล และไม่เคยได้รับข้อมูลจาก Google Calendar ของคุณ — แม้ในกรณีที่คุณเปิดฟีเจอร์ "ดึงนัดจากปฏิทิน" เอง ขั้นตอนการดึงก็เป็นการอ่านชื่อนัดกับเวลามาลงตารางตรงๆ ไม่ผ่านระบบ AI

YES BOSS's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data (including calendar data) is never used, transferred, or sold to develop, train, or improve any AI/ML model, and is never shared with any third-party AI provider. The AI service YES BOSS uses solely interprets messages the user types; it is accessed via an API that does not train on submitted data and never receives the user's Google Calendar data — including when the user explicitly enables the opt-in "import events" feature, which reads only event titles and times to create matching reminders and does not pass them to any AI service.

7. เก็บข้อมูลไว้นานแค่ไหน

  • ข้อความที่คุยกับเลขา — เก็บไม่เกิน 180 วัน จากนั้นระบบลบอัตโนมัติทุกคืน · สิ่งที่คุณสั่งให้ "จด" ไว้ (งาน นัด รายการเงิน ความจำ) ไม่ถูกลบไปด้วย
  • ดัชนีค้นหาย้อนหลังของแพ็กเกจฟรี — เก็บ 60 วัน (แพ็กเกจ Pro ค้นได้ยาวกว่านั้น)
  • บันทึกการใช้คำสั่งในกลุ่ม LINE — เก็บ 90 วัน
  • งาน นัด รายรับรายจ่าย ไฟล์ และความจำที่ให้เลขาจด — เก็บตลอดที่คุณยังใช้บริการ เพราะเป็นสิ่งที่คุณตั้งใจให้จำ
  • นัดที่ดึงมาจากปฏิทิน (เฉพาะคนที่เปิดฟีเจอร์เอง) — เก็บเท่ากับนัดทั่วไป และถ้าคุณลบนัดนั้นในปฏิทิน Google ระบบจะยกเลิกรายการฝั่งเราให้เองภายใน 15 นาที · ปิดฟีเจอร์แล้วเราหยุดอ่านปฏิทินทันที
  • ข้อมูลสำรอง (backup) — สำรองวันละ 2 รอบเพื่อกันข้อมูลสูญหาย และชุดสำรองเก่าถูกทำลายภายใน 30 วัน · เมื่อคุณขอลบข้อมูล ข้อมูลในระบบหลักหายทันที ส่วนที่ค้างในชุดสำรองจะหมดอายุตามรอบนี้และไม่ถูกนำกลับมาใช้
  • เมื่อขอลบหรือเลิกใช้ — พิมพ์ "ลบข้อมูลของฉัน" แล้วยืนยันอีกครั้ง ระบบลบทั้งข้อความ ไฟล์ และทุกรายการทันที · ถ้าขั้นตอนใดล้มเหลว ระบบจะตามลบซ้ำให้เองจนครบ และมีบันทึกทุกครั้ง

8. สิทธิของคุณตาม PDPA (ครบทั้ง 8 ข้อ)

  • สิทธิเข้าถึงและขอสำเนา — กดปุ่ม "ดาวน์โหลดข้อมูลของฉัน" ในแท็บ "โปรไฟล์" ของ My YES BOSS ได้ไฟล์ข้อมูลของคุณทันที ไม่ต้องรออนุมัติ
  • สิทธิแก้ไขข้อมูล — แก้ชื่อ เบอร์ วันเกิด ฯลฯ ได้เองในแอป หรือบอกเลขาในแชต
  • สิทธิลบข้อมูล — พิมพ์ "ลบข้อมูลของฉัน" ในแชต ระบบลบทั้งหมดทันที
  • สิทธิเพิกถอนความยินยอม — ถอนเมื่อไหร่ก็ได้ ไม่กระทบความชอบด้วยกฎหมายของการประมวลผลก่อนหน้า
  • สิทธิคัดค้านการประมวลผล — แจ้งผ่านปุ่ม "คุยกับทีมงาน"
  • สิทธิขอระงับการใช้ข้อมูล — แจ้งผ่านปุ่ม "คุยกับทีมงาน"
